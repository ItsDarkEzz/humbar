## Зачем Humbar

Вырез — единственное место на экране, куда взгляд падает постоянно, но которое ничего не делает. Humbar превращает его в спокойный центр Mac: что играет и какие слова звучат прямо сейчас, сообщение, которое только что пришло, идущий таймер. А когда Claude Code, Codex, OpenCode или Droid нужно ваше решение, вопрос появляется тут же — не нужно искать вкладку терминала.

Все функции бесплатны 7 дней, потом — **$3.99 один раз**: без подписки и аккаунта, все обновления включены. Своего сервера у Humbar нет: с Mac уходит только то, что явно нужно конкретной функции.

## Установка

1. Скачайте **`Humbar-<версия>.dmg`** в [Releases](https://github.com/ItsDarkEzz/humbar/releases/latest).
2. Перетащите Humbar в **«Программы»** и откройте.
3. Приложение пока не подписано сертификатом Apple Developer, поэтому при первом запуске macOS предупредит. Откройте **Системные настройки → Конфиденциальность и безопасность** и нажмите **«Всё равно открыть»** — один раз.

Дальше окно приветствия проведёт через разрешения и подключения. Всё нужное уже внутри. Требования: **macOS 15.4+**, **Apple Silicon**. Интерфейс на русском и английском, язык берётся из системы (его можно сменить в Настройки → Система).

## Подключение агентов

Откройте **Настройки → ИИ-агенты** и нажмите **«Подключить»** рядом с нужным агентом.

| Агент | Как подключается | Что на острове |
|---|---|---|
| Claude Code | HTTP-хуки в `~/.claude/settings.json` | сессии, разрешения, вопросы, планы, «готово» |
| Codex | командные хуки в `~/.codex/hooks.json` (один раз доверьте им в `/hooks`) | сессии, разрешения |
| OpenCode | плагин в `~/.config/opencode/plugins` | сессии, разрешения со «Всегда», вопросы |
| Droid | командные хуки в `~/.factory/settings.json` | сессии, «готово», «ждёт разрешения» |

Перед изменением каждого файла делается резервная копия, а **«Отключить»** убирает только записи Humbar. Если Humbar не запущен, агенты работают так, будто его нет.

## Приватность

- **Ни своего сервера, ни аналитики, ни связки ключей.**
- Источники текстов получают только название трека, исполнителя и длительность. Тексты на диск не сохраняются.
- Хуки агентов общаются только с `127.0.0.1:47431` и защищены случайным токеном этой установки.
- Список питомцев сообщества (по желанию) запрашивается с `codex-pets.net` только когда вы нажимаете «Показать» в настройках; при установке питомца его пакет скачивается оттуда же. Питомцы — работы сторонних авторов, они не входят в Humbar.
- Лимит Claude (по желанию) берёт вход самого Claude Code из `~/.claude/.credentials.json` и запрашивает расход у `api.anthropic.com`.
- Вход в Яндекс хранится в `~/Library/Application Support/Humbar/yandex.json`, доступном только вашему пользователю.

<details>
<summary><b>Сколько стоит?</b></summary>

<details>
<summary><b>Почему macOS пишет, что не может проверить разработчика?</b></summary>

Приложение пока не заверено сертификатом Apple Developer. Откройте **Системные настройки → Конфиденциальность и безопасность** и нажмите **«Всё равно открыть»** — один раз.
</details>

<details>
<summary><b>Работает ли на Mac без выреза?</b></summary>

Humbar сделан для MacBook с вырезом. На других экранах остров стоит сверху по центру, но всё задумано вокруг выреза.
</details>

<details>
<summary><b>Не будет ли конфликта с другими приложениями для выреза?</b></summary>

Используйте одно такое приложение за раз — все они рисуют в одном месте.
</details>

<details>
<summary><b>Какие части держатся на неофициальных API?</b></summary>

«Сейчас играет» читается через закрытый фреймворк Apple MediaRemote с помощью встроенного [media-control](https://github.com/ungive/media-control). Вход в Яндекс Музыку представляется Android-клиентом Яндекс Музыки, как открытая библиотека [yandex-music-api](https://github.com/MarshalX/yandex-music-api). Адрес расхода Claude не документирован, NetEase, Kugou и котировки Yahoo тоже неофициальные. Любой из них может измениться без предупреждения.
</details>
